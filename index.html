Assumptions

Same tokens for each model: every request is assumed to use 64,000 input tokens and 400 output tokens, with 90% of input cached, whether served by Luna, Terra or GLM. In practice models may use different token counts, have different cache hits and need different numbers of retries; quality is not assumed to be equal.

Selected OpenAI pricing: — per million tokens (uncached input / cached input / output). Cache-write charges are excluded.

Usage: 16 daytime and 8 night-time hours, repeated for 30 days. The usage percentages measure useful throughput relative to the benchmark, not GPU hardware utilisation. Bursts, queues and latency are not modelled.

GPU benchmark: GLM-5.3 on 16 GPUs, using NVIDIA’s 190.048 output tokens/sec/GPU for B200 or 84.335 for H200. Its benchmark uses median 64K input and 400 output tokens, 90% cache hits and simulated speculative decoding. Medians are treated as averages, and the same throughput is assumed at all usage levels. Actual performance can differ.

Other costs: GPU rental is billed for every hour on, even if idle. Storage, networking, staff, taxes, cache writes, retries, availability and startup costs are excluded. Stopping GPUs at night may not save money under a commitment that bills stopped capacity.

Break-even: the displayed discount makes the 24/7 GPU cost equal to the selected OpenAI model; a larger discount is needed to be cheaper. At zero usage, free GPUs can only match a $0 API bill.

Prices checked 23 November 2026. Flex is slower or may be unavailable; OpenAI is winding down the beta without a confirmed retirement date.
